## Bonus 练习内容

### 基础练习

1. **xyz 排序**：输入三个整数，按从大到小的顺序输出。
2. **九九乘法表**：使用嵌套循环输出乘法表。
3. **字符串处理**：将 `ol` 替换为 `fzu`，再反向输出字符串。
4. **输入列表**：筛选列表中的整数并排序。
5. **创建字典**：遍历字典并删除编号为偶数的条目。
6. **函数**：统计输入中各元素出现的次数。
7. **商品类**：封装商品信息，实现信息展示、修改和销售收入计算。
8. **斗地主发牌**：随机分发 54 张牌，为三名玩家各分配 17 张牌，并保留 3 张底牌。

### 进阶练习

1. **装饰器**：记录函数名称、开始时间、结束时间和运行时长。
2. **斗地主发牌**：在随机发牌的基础上，按牌面大小对每手牌排序。
3. **列表推导式**：创建二维列表并进行转置。
4. **类的魔术方法**：通过 `MyZoo` 练习 `__init__`、`__str__`、`__eq__` 和 `__len__`。
5. **正则表达式**：使用 `re.fullmatch` 校验输入的密码格式。

## 运行方式

安装 Python 3 后，在仓库根目录运行对应脚本。当前练习仅使用 Python 标准库，无需安装第三方依赖。

```bash
# Hello, World!
python3 "Task 0/作业3/HelloWorld.py"

# A+B：运行后输入两个整数，例如 3 5，程序输出 8
python3 "Task 0/作业4/1-AplusB.py"

# 九九乘法表
python3 "Task 0/Bonus-基础/2-九九乘法表.py"

# 带排序的斗地主发牌
python3 "Task 0/Bonus-进阶/2-斗地主发牌/main.py"
```

路径包含空格，运行命令时请保留引号。需要输入的练习会在终端等待输入。

两个斗地主脚本都会在各自脚本所在目录生成或覆盖 `player1.txt`、`player2.txt`、`player3.txt` 和 `others.txt`，分别保存三名玩家的手牌和底牌。
